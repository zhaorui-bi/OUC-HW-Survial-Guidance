    OUC-HWU 计科中外生存指南¶

    把中外合作办学的规则、课程、科研与升学路径,一次讲清楚。

    OUC × HWU Computer Science Joint Programme · 中国海洋大学 × 赫瑞瓦特大学 · 由学生维护,持续更新

    关于 · 动态 · 阶段路线 · 六大板块 · 专题导航 · 贡献者

    开始阅读 GitHub 仓库

    关于¶

    本指南面向 OUC-HWU 计科中外合作办学项目学生,系统梳理培养规则、课程学习、语言要求、科研训练、升学申请、赴英准备与留学生活等关键议题。项目同时涉及中英两套培养与评价体系,信息分散且更新频繁,我们希望把学生视角的经验沉淀成一份可持续维护的知识库。

    文档形态

    非官方学生知识库,以学生经验和公开资料为基础,不替代学校、学院、签证中心或目标院校的正式通知。

    维护团队

    发起人 / 维护者:Zhaorui(Elijah) Jiang,与各专题贡献者共同维护,详见贡献者。

    通过 GitHub Issues 或 Pull Request 补充经验、修复链接与更新政策;请勿提交个人隐私或未授权材料。

    项目篇¶

    计算机科学与技术(中外合作办学)是双学籍注册项目。

    项目特点

    你会同时拥有中方和英方的成绩单 / 在读证明。保研、夏令营、预推免和海外申请时都可能用到,但申请时请如实递交中英双方材料。

    1. 中国海洋大学:Bachelor of Engineering in Computer Science and Technology
    2. 微信公众号:中国海洋大学计算机学院。毕业去向、学子访谈、课程跟踪等内容可以往前翻。
    3. 信息科学与工程学部官网:http://it.ouc.edu.cn/main.htm
    4. 科研进组给老师写 email 时,建议先根据学院官网找到老师主页。
    5. 赫瑞瓦特大学:Bachelor of Engineering in Robotics (F2R8-ROB)
    6. 英方项目介绍:课程页面
    7. MACS 学院 CS 部门官网:Computer Science
    8. HWU CS 学生信息官网:Student information

    赫瑞瓦特大学成绩单开具链接:Student Service Portal

    2024 级计算机科学与技术(中外合作办学)宿舍情况:

    • 大一:崂山校区。一般情况下是四人间,中海苑是六人间但很新。
    • 大二 + 大三:西海岸校区。独立卫浴 + 四人间。
    • 大四:赫瑞瓦特大学爱丁堡校区附近。traditional / modern 单人间。

    英语篇¶

    Heriot-Watt University 入学英语要求如下表第三列,总分和小分都必须达标。

    一般情况下建议考 IELTS Academic。学术英语课也会围绕雅思相关内容展开。如果有强烈赴美深造意愿,也可以选择 TOEFL iBT,但一定要注意小分要求。

    为什么英语能力重要?

    • 赫瑞瓦特大学要求达到 IELTS 6.0(各单项 5.5)或其他同等语言成绩。不达标虽然有语言班,但费用很高。
    • 出国申请中,亮眼的雅思或托福成绩是必备项,也是加分项。
    • 国内保研和出国申请面试都可能是英文面试。
    • CS 和 AI 前沿内容主要以英文论文、课程和文档呈现。
    • 大四、硕士、博士阶段的学习、沟通和学术交流都需要英语能力支撑。

    中国海洋大学 GPA 计算规则¶

    刷分问题¶

    赫瑞瓦特大学成绩单(英方成绩单)不支持刷分,即第一次考试成绩为最终成绩单分数。

    英方课程:F2R8-ROB curriculum

    中国海洋大学成绩单(中方成绩单)支持刷分,同名课程取最高。也就是说,英方课程如果刷分,英方成绩单不更新,但中方成绩单会更新。

    刷分策略:

    • 尽量刷高学分课程。
    • 尽可能刷超低分课程。
    • 多修高分通识课以抬高均分。

    保研特别注意

    保研成绩计算通常只看第一次初修成绩,刷分对保研排名可能无效。具体以当年学院政策为准。

    科研篇¶

    科研训练具有较强的目标差异性,但越早理解其与升学目标之间的关系,越有利于形成稳定的长期规划。

    目标 科研权重 建议
    海博 权重较高 建议尽早开始,并形成明确产出
    保研 重要补充到关键加分 高竞争度院校建议具备科研产出
    海硕 视目标学校而定 大多数情况下绩点仍是主线

    备注:计科中外保研率根据 2020 级情况大概在 20% 左右。

    必修模块 ML(2 选 1)和 DL 模块建议认真学,熟悉 PyTorch 深度学习框架。后续可以根据兴趣选择 CV、NLP、GNN、XAI 等方向。

    毕业设计提醒

    前三年即使没有深入学习 AI / ML,大四毕业设计也大概率需要接触相关内容,建议提前建立基础。
