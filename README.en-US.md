## How to Use

It is recommended to read the online documentation first:

[https://ouc-hw-survial-guidance.readthedocs.io/zh-cn/latest/](https://ouc-hw-survial-guidance.readthedocs.io/zh-cn/latest/)

You can select topics based on your current stage:

| Scenario | Recommended Reading |
| --- | --- |
| New to the program, want to understand the curriculum structure | Home, Program Basics, Courses & Grades |
| Preparing for domestic graduate recommendations, overseas applications, or summer programs | Domestic Grad Recommendation Planning, Overseas Grad Application Planning, Summer Research and Summer School Applications, Undergraduate Research Guide |
| Preparing to study and live in the UK | IELTS Preparation, Pre-departure Checklist, International Student Cooking Recipes |
| Exploring directions or supplementing skills | AI4Science Learning Plan, Robotics Learning Plan, Computational Physics, Verilog Usage Guide |

This document compiles student experiences and publicly available information, and does not replace official notices from the university, college, visa centers, or target institutions. For critical matters such as curriculum plans, language requirements, application rules, visas, and accommodation, always refer to the official notifications of the respective year.

## Maintenance Guidelines

To avoid content duplication, this repository only maintains one primary entry point:

**Main content is uniformly maintained in the `Survial_Guide/docs/` directory.**

Please follow these principles when maintaining:

1. When modifying the main text, prioritize editing the corresponding topic pages. Do not add duplicate Markdown files to the repository root directory.
2. When adding new topics, please include the title, target audience, update time, and source information.
3. For information involving policies, application requirements, course schedules, or fees, please specify the applicable year and remind readers to double-check official notices.
4. When submitting or supplementing cases, avoid disclosing personal privacy, unauthorized chat logs, application materials, and sensitive identity information.
5. When errors, broken links, or outdated content are found, it is recommended to submit errata via Issues.

`README.md` serves only as the GitHub repository entry page and does not contain the full text; the Read the Docs page is the official reading version.

## Contributing

Supplementing course experiences, application timelines, research training, UK preparation, life guides, and resource links are all welcome. It is recommended to participate via the following methods:

- Submit questions, errata, or supplementary suggestions via Issues.
- Directly modify the corresponding topics in `Survial_Guide/docs/` and submit a Pull Request.
- If contributing personal experience, please indicate the applicable cohort, background conditions, and potential expiration dates to the best of your ability.
